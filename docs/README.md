# مستندات MSN-GUARD

- [معماری](architecture.md) — مرزهای لایهٔ اندروید، پل JNI و هستهٔ Rust.
- [راهنمای ساخت](build.md) — ساخت محلی APK دیباگ برای معماری‌های پشتیبانی‌شده.

معرفی پروژه و لینک دانلود و قواعد مشارکت و گزارش امنیتی در [README اصلی](../README.md) آمده است.

## دارایی‌های برند

| فایل | کاربرد |
|---|---|
| `logo.png` | لوگوی اصلی ۱۰۲۴×۱۰۲۴ — منبع همهٔ آیکون‌ها |
| `logo-512.png` | نسخهٔ ۵۱۲×۵۱۲ برای فروشگاه و README |

آیکون برنامه از همین لوگو ساخته می‌شود. لایه‌های adaptive icon در پوشهٔ `app/src/main/res/drawable-nodpi/` با نام‌های `msnguard_icon_fg.png` و `msnguard_icon_bg.png` قرار دارند.

جای برش این لایه‌ها اندازه‌گیری شده، نه چشمی: حلقهٔ نئون بیرونی روی شعاع ۳۳۴ از ۵۱۲ است و هر لانچری فقط داخل شعاع ۳۴۱ را تضمین می‌کند، پس حلقه و نگین و حرف M کامل داخل محدودهٔ امن می‌مانند و هیچ ماسکی آن‌ها را نمی‌بُرد.
